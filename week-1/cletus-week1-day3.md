## Key concepts
- Base model: just continues text.
- Chat model: base model fine-tuned on conversations (RLHF), so it follows instructions.
- Reasoning model: thinks step by step first. Better at logic, maths and code. Slower and pricier.
- Good at: summarizing, drafting from an outline, code.
- Weak at: recent events (knowledge cutoff), niche topics, hallucinations, counting letters.
- Agentic AI: plans and uses tools over many steps. Deep Research, Claude Code, ChatGPT Agent Mode.
- LLM competition game: models playing against each other to compare them.
