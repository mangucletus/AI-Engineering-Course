Ophelia: Week 2, Day 4 - Tools

# Tools

- Tools - allows frontier models to connect with external functions

1. For Richer responses by extending knowledge
2. Ability to carry out actions within the application
3. Enhanced capabilities like Calculations

# Tool Calling

- LLMs outputs / produces tokens
- Tool calling in theory means An LLM decides to run code on my computer

- In practice, Code calls an LLM for a response and the LLM directs the code to call a tool. The code calls the tool and have a conversation history of the conversation to the LLM which now acts on the history of the conversation to respond to the Code.

# Uses of Tools

1. Fetching data or adding knowledge or Context
2. Taking action, like booking a Meeting
3. Perform Calculations or run code
4. Modifying the UI
